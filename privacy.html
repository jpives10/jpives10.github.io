Privacy policy

This policy describes data handling by Justin Ivey's FLL VMS Collector Personal application and this information website.

Information accessed

The collector downloads volunteer reports from the FIRST Volunteer Management System using an authorized browser session. Reports may contain volunteer contact details, applications, assignments, service history, alumni status, and other fields supplied in the selected VMS export.

For Google Drive, the application uses the account email address to verify the authorized account. It accesses the names, identifiers, hierarchy, capabilities, checksums, and contents of files and folders authorized for the application through Google's per-file access permission.

Purpose and use

Google user information is used solely to authenticate the operator, confirm authorized destinations, store volunteer reports, and verify the integrity and completeness of report collections for volunteer program administration.

The collector records collection dates, run identifiers, event and report identifiers, validation results, file checksums, and publication results so failures can be investigated.

Storage and access

Reports, manifests, and verification copies are stored in private staging on the operator's Mac. Validated files and collection controls are published to the designated Google Drive folders.

Google OAuth refresh credentials are stored in the operator's macOS Keychain. The FIRST browser session is maintained in the collector's dedicated local Chrome profile. Access to published report files follows the permissions configured on their Google Drive destinations.

The information website contains public application information. Report collection and Google authorization take place through the local application and Google's authorization service.

Retention and user controls

Collected files and collection records are retained for volunteer administration and troubleshooting until the operator removes them under the program's record-handling practices. Existing historical exports are preserved by the collector.

The operator can revoke the application's Google access through their Google Account's third-party connections settings. Revocation stops future authorized access. Copies already stored locally or in Google Drive require separate review and removal by their authorized administrator.

Website hosting

This information website is prepared for GitHub Pages hosting. When published there, GitHub handles website requests according to its privacy statement, which describes information such as IP addresses and request logs.
